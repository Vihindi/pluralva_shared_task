## 1. Preprocessing (`src/preprocess.py`) — EXECUTED ✅

`python src/preprocess.py` → `processed/*.jsonl` + `processed/stats.json`

**Unified schema** (all three files): `uid, dataset, value_native, value_english,
scenario, question, options, gold, fold` + dataset-specific fields below.

Decisions made, per dataset:

**Chinese (790/790 kept, 0 problems).**
Straight normalization; gold validated against {A,B,C,D}; all four options
verified non-empty; the value taxonomy kept in both languages (it is part of
the test-time schema and is used in every prompt).

**Indonesian (366/366 kept).** The raw `Gold_Answer` ("A, A, A, A, C") is *not*
collapsed to one label. Each record stores:
- `votes` — the 5 raw annotator votes;
- `vote_dist` — empirical distribution over A–D (the soft label);
- `consensus` — all labels tied at maximum frequency (**a prediction is correct
  iff it lands in this set** — this is the official scoring rule and is what
  `evaluate.py` implements);
- `agreement` — plurality strength 2–5 (kept for error analysis: the 103
  agreement-2 items are structurally noisy);
- `gold` — first consensus label, used only for stratification/reporting.

**Sri Lankan (203/203 kept).** Gold normalized ("None" → `"0"`, matching both
the dev data and the submission spec). Each record additionally stores the
**binary decomposition**: `stmt_A_ok = gold ∈ {A, Both}`, `stmt_B_ok = gold ∈
{B, Both}`. Verified: composing the two booleans back always reproduces the
4-way gold.

**Cross-validation folds.** Deterministic stratified 5-fold (seed 42), written
into each record as `fold` so every downstream artifact inherits the same
split. Strata: gold label (ZH, SI) / consensus-set signature (ID) — this keeps
the skewed label priors stable across folds (measured: worst per-fold deviation
0.5 pp for ZH, 2.1 pp for SI), which matters because prior calibration at
inference is estimated from training folds. Fold sizes: ZH 158×5, ID 74/73×5,
SI 41/41/41/40/40.

**Validation performed:** label-set checks, empty-option checks, duplicate-UID
check, per-fold prior report — all clean, `stats.json` has the numbers.

## 2. Prompt templates (`src/prompts.py`)

One template family per country, each in `direct` (answer-only) and `cot`
(reason-then-answer) variants, all ending in a uniform machine-parseable
`Answer: X` line, and **all value-conditioned** (the annotated value is in the
test schema, and it is the strongest single hint in the Chinese data):

| Country | Instruction language | Rationale |
|---|---|---|
| Chinese | Chinese | base model strongest in zh; native judgment task |
| Indonesian | Indonesian | native Pancasila framing ("penilaian mayoritas masyarakat Indonesia" — matches the consensus-of-annotators gold definition) |
| Sri Lankan | English instructions, Sinhala content untouched | English-pivoted reasoning helps low-resource inputs ([arXiv:2504.02890](https://arxiv.org/abs/2504.02890)); native content preserved (SinhalaMMLU: translations lose fluency/meaning) |

Sri Lankan primary prompt is the **binary judgment** ("is this statement a
correct and appropriate answer to the question, per the given value?") asked
independently for statements A and B; the 4-way prompt is kept as a baseline
for comparison. Framing it as "correct answer to the question" (not "aligned
with the value") is deliberate: some SI items are negated questions ("which is
NOT a factor…"), where value-alignment of the statement and correctness of the
answer diverge.

## 3. SFT data construction (`src/build_sft_data.py`) — EXECUTED ✅

`python src/build_sft_data.py` (re-run with `--rationales processed/rationales.jsonl`
after bootstrapping) → `sft_data/`

| | source items | SFT examples (full) | construction |
|---|---|---|---|
| zh | 790 | 3,160 | 4 cyclic option permutations × 1 gold target |
| id | 366 | 7,320 | 4 cyclic permutations × 5 vote-expanded targets |
| si | 203 | 406 | 2 binary judgments (statement A / statement B) |

Key mechanics, all unit-verified:

- **Cyclic option-permutation augmentation (ZH/ID).** Each item appears under 4
  option orderings with gold letters / vote letters remapped. Verified: the
  gold *content* is preserved under every permutation, and remapped Indonesian
  votes still produce a consistent consensus. Purpose: order-invariance
  (mitigates MCQ selection bias, [Zheng et al. 2024](https://arxiv.org/abs/2309.03882))
  + 4× data from a tiny training pool.
- **Indonesian vote-expansion = soft-label training.** One example per
  annotator vote (5 per item-permutation). Expectation over per-example CE
  gradients equals soft cross-entropy against the empirical vote distribution —
  soft-label learning ([Plank 2022](https://arxiv.org/abs/2211.02570)) with no
  custom loss code, so any standard SFT trainer works.
- **Sri Lankan binary decomposition.** 406 Yes/No examples whose label balance
  is far better than the 4-way skew (Yes-rate: statement A 73%, statement B 38%)
  and which contain zero positional signal by construction.
- **Fold discipline.** `*_train_fold{k}.jsonl` contains only examples whose
  source item is *outside* fold k (leakage-checked); `*_train_full.jsonl` is for
  the final submission model only.
- Output is chat-format JSONL (`messages` + `meta`), directly consumable by trl.

**Verification run** (permutation round-trips, decomposition round-trip,
fold leakage, target format `Answer: (A|B|C|D|Yes|No)`, stratification
stability): **15/15 checks passed.**

## 4. Rationale bootstrapping (`src/bootstrap_rationales.py`) — GPU, ready to run

STaR-style ([Zelikman et al. 2022](https://arxiv.org/abs/2203.14465)): sample
k=8 value-conditioned CoT chains per target from the untuned base model, keep
the first chain whose parsed final answer is correct (ID: lands in the
consensus set; SI: per-binary-judgment), strip the answer line, store the
rationale. Items with no correct chain fall back to **rationalization** (gold
revealed, model justifies; tagged `source="rationalized"` so the two can be
ablated). Resumable (appends, skips done keys); Qwen3 thinking mode disabled
for clean rationales.

```bash
python src/bootstrap_rationales.py --model Qwen/Qwen3-8B --k 8            # A100/L4
python src/bootstrap_rationales.py --model Qwen/Qwen3-8B --k 8 --load_4bit # T4/16GB
# then rebuild SFT data with rationales:
python src/build_sft_data.py --rationales processed/rationales.jsonl
```

## 5. LoRA training (`src/train_lora.py`) — GPU, ready to run

trl `SFTTrainer` with `assistant_only_loss=True` (loss only on the rationale +
`Answer: X` tokens — the letter-likelihood objective), LoRA r=16 α=32 on all
attention + MLP projections, 2 epochs, lr 1e-4 cosine, effective batch 16,
bf16 + gradient checkpointing, `--load_4bit` for QLoRA on 16–24 GB GPUs.

```bash
# per-country CV adapters (5 folds × 3 countries):
python src/train_lora.py --train_files sft_data/zh_train_fold0.jsonl --output_dir runs/zh_fold0
# joint adapter (country conditioning lives in the system prompts):
python src/train_lora.py --train_files sft_data/zh_train_fold0.jsonl \
    sft_data/id_train_fold0.jsonl sft_data/si_train_fold0.jsonl --output_dir runs/joint_fold0
# final submission model (all dev data):
python src/train_lora.py --train_files sft_data/zh_train_full.jsonl \
    sft_data/id_train_full.jsonl sft_data/si_train_full.jsonl --output_dir runs/joint_full
```

## 6. Evaluation & prediction (`src/evaluate.py`) — GPU, ready to run

- **Constrained scoring** — sums token logprobs of each `Answer: X` continuation
  after the chat generation prompt; argmax over the legal label set only, so
  invalid outputs are impossible.
- **Permutation ensemble** (`--n_perms 4`) — content-level probabilities averaged
  over cyclic orderings (position debiasing *without* a uniformity assumption).
- **Prior calibration** (`--prior_tau`) — multiplies by prior^τ estimated from
  **training folds only** (or full dev when predicting on test); τ tuned on CV.
- **Sri Lankan composition** — P(Yes) per statement, `--si_threshold` (default
  0.5, tunable on folds) composes A / B / Both / 0.
- **Correctness rules** — ZH/SI exact match; ID membership in the consensus set.
- Reports per-country accuracy + macro-average, writes per-item details for
  error analysis, and in `predict` mode emits submission-format
  `predictions.jsonl` (`{"dataset", "id", "LLM_Output"}`, SI "neither" = `"0"`).

```bash
# zero-shot baseline (base-model bake-off), fold 0:
python src/evaluate.py eval --model Qwen/Qwen3-8B --fold 0
# fold-0 adapter with permutation ensemble + calibration:
python src/evaluate.py eval --model Qwen/Qwen3-8B --adapter runs/joint_fold0 \
    --fold 0 --n_perms 4 --prior_tau 0.5
# final predictions on hidden test:
python src/evaluate.py predict --model Qwen/Qwen3-8B --adapter runs/joint_full \
    --n_perms 4 --prior_tau 0.5 \
    --test_files test/chinese_test.jsonl test/indonesian_test.jsonl test/sri_lankan_test.jsonl \
    --out predictions.jsonl
```

## Stage-1 run order (on the GPU machine)

1. `pip install -r requirements-gpu.txt`; copy `processed/` + `src/` (already generated).
2. Zero-shot bake-off: `evaluate.py eval --fold 0` for Qwen3-8B / Llama-3.1-8B /
   Qwen2.5-7B / Aya-Expanse-8B / Sailor2-8B → lock the base (macro-best).
3. `bootstrap_rationales.py` with the locked base → `processed/rationales.jsonl`.
4. `build_sft_data.py --rationales processed/rationales.jsonl` (regenerates sft_data with CoT targets).
5. Train fold adapters (per-country and joint), eval each fold: pick
   joint-vs-per-country, τ, SI threshold on CV — never on the full dev set.
6. Train `runs/joint_full` on all data with the locked config → hold for submission.

## Deliberate deviations / notes

- **Bootstrapped rationales are only attached to the canonical option order**;
  the 3 permuted copies keep bare `Answer: X` targets (a rationale references
  option letters, which change under permutation). Mixing rationale and direct
  targets is intentional — the model learns both to reason and to answer directly.
- **No retrieval anywhere** (Track-1 rules ambiguity — see METHODOLOGY §2.7).
- **Submission `dataset` field names** default to `chinese/indonesian/sri_lankan`
  in `evaluate.py`; confirm the exact expected strings when the test set is
  released (single dict to change).
- Stage 2 (DPO/GRPO for ZH, SI threshold calibration sweep) and Stage 3
  (self-consistency + fold-ensemble) are not yet implemented — Stage-1 CV
  results should decide where that effort goes.
